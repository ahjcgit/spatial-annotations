# Identity review surface

Mode: Operate. This is an extension of `demo/evaluation.html`, not a new visual identity.
The researcher selects a recording and H0–H4 run, scrubs a frame, and checks associations
and reasoning events. Preserve the incumbent system font, dark camera-review surface,
plain form controls, and readable table vocabulary. No marketing copy or decorative data.

The image and timeline lead; identities and reasoning sit alongside on desktop and below
on narrow screens. Evaluation truth is opt-in and labeled separately. Incorrect, matched,
and unknown have both text labels and colors. Private annotation contents are not exported.
Async frame changes must discard old responses; failed loads have a visible retry path.
