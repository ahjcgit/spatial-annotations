Connecting…

1. Record a condition

Use the same marked near/middle/far positions, lighting and background. Only the named test object should be visible. These are approximate conditions, not measured centimeters or degrees.

Still: hold steady. Pan: keep the object stationary and turn your head. Exit/reenter: look away briefly, then return. Each repeat should start after repositioning.

Live preview — not a recorded trial

The preview is a snapshot. Recorded frames are fresh results sampled from the running demo; they are not all sensor frames.

2. Mark the actual object — saved trial images

Click two opposite corners of a tight box around the visible object, or drag to draw one. Predictions are hidden during annotation. Mark “Absent” only when the object is out of view; a detector miss is still “Visible.” Use “Uncertain” for frames you cannot judge.

No box drawn

For nearly still frames, copy the previous box, check its fit, then save. Redraw if the object moved. Copying never saves automatically.

Every frame needs review for its trial to enter the condition comparison. Uncertain frames keep a trial out of that comparison. CSVs preserve partial review and coverage.

3. Compare and export

NanoDet Plus (416) and YOLOX-S (640), on identical saved images using the computer CPU. Replay pauses the live demo and resumes it afterward. Timing excludes the camera, network and display.
